# 去中心化二手买卖平台

## 项目简介

这是一个基于密码学与区块链技术的去中心化二手买卖平台，专为二手书交易设计。平台通过区块链技术确保交易记录的不可篡改性，通过密码学技术保障交易的安全性和真实性。

## 技术栈

- **前端**：HTML, CSS, JavaScript
- **后端**：Python
- **区块链**：自定义区块链实现
- **密码学**：Ed25519数字签名
- **数据库**：MySQL

## 核心功能

### 1. 身份管理
- 生成新身份（密钥对）
- 查看身份指纹（公钥）
- 导出身份（备份）
- 导入身份（恢复）

### 2. 交易管理
- 发布新交易
- 查看交易列表
- 加入交易（买家）
- 完成交易（双方签名）
- 取消交易

### 3. 区块链
- 交易记录上链
- 区块导出
- 确保交易记录不可篡改

### 4. 聊天系统
- 买卖双方实时沟通
- 支持交易完成请求的发送和处理

## 交易流程

1. **发布交易**：卖家填写交易信息（描述、价格）并发布
2. **加入交易**：买家浏览交易列表，选择感兴趣的交易并加入
3. **沟通协商**：买卖双方通过聊天系统进行沟通
4. **完成交易**：
   - 一方发起交易完成请求
   - 另一方验证并签名
   - 双方签名提交后，交易完成并上链
5. **取消交易**：任一方可取消未完成的交易

## 安全特性

- **数字签名**：使用Ed25519算法进行数字签名，确保交易的真实性
- **区块链**：交易记录上链，确保不可篡改
- **身份管理**：用户身份基于密码学密钥对，保护隐私
- **哈希验证**：交易内容和签名通过哈希验证，防止篡改

### 后端

2. 创建数据库并导入 `schema.sql`
3. 运行 `server/app.py` 启动后端服务

## 关键技术点

### 1. 区块链实现
- 区块结构：包含索引、前哈希、当前哈希、时间戳、类型和 payload
- 哈希计算：使用SHA-256算法
- 区块链接：通过前哈希确保区块链的完整性

### 2. 密码学应用
- 密钥生成：使用Ed25519算法生成密钥对
- 数字签名：交易操作需要签名验证
- 哈希计算：确保数据完整性

### 3. 交易安全
- 交易ID：基于交易内容哈希生成
- 双重签名：交易完成需要买卖双方签名
- 签名验证：确保签名的有效性
